# Сверка Java-приложения с исходными материалами и EXE

Дата проверки: 12 октября 2026 г. Источники оригиналов — ветка `origin/semester-7-real-time-information-systems-labs` репозитория MyUniversity. В этом документе отделены измеренные результаты Java, наблюдения интерфейса EXE и выводы, которые пока нельзя подтвердить.

## Какой документ проверен

`ISRV pr STUDENT/ISRV pr 1.pdf` — это пятистраничное «Практическое занятие № 1» на тему выбора звеньев измерительного канала ИИС. Это расчётное занятие, а не отчёт с результатами выполнения лабораторной №1. Оно не описывает опыт со спектром, автокорреляцией или фильтрами из методички ЛР1, поэтому числа документа нельзя использовать как эталон для `Signal.exe`, `Lab.exe` или `SRV.exe`. В `лабораторные/лаб-1/README.md` также отмечено, что эмпирические измерения для лабораторной ещё не получены. Другого отчёта с численными результатами спектральной ЛР1 в исследованной ветке не найдено.

В самом практическом занятии обнаружены арифметические и методические расхождения:

| Проверка из PDF | Расчёт | Примечание |
|---|---:|---|
| Частота 3000 отсчётов/с суммарно | интервал `1/3000 = 333,3 мкс` | В тексте округлено до 330 мкс. |
| ЭВМ2: 30 операций на отсчёт при 100 000 операций/с | `30/100000 = 300 мкс` | На печатной стр. −6 есть опечатка «30 мкс»; стр. −7 указывает 300 мкс. Верно 300 мкс. ЭВМ1 имеет 200 000 операций/с и занимает 150 мкс. |
| УСД1 + ЭВМ1 / ЭВМ2 | `220+150=370 мкс`; `220+300=520 мкс` | Оба варианта медленнее интервала 333,3 мкс. |
| УСД2 + ЭВМ1 / ЭВМ2 | `30+150=180 мкс`; `30+300=330 мкс` | Оба варианта проходят условие без буфера. |
| Память за 10 с, УСД1 | `2000·10·2 = 40000` байт | Не помещается ни в 16, ни в 32 КиБ. |
| Память за 10 с, УСД2 | `3000·10·1 = 30000` байт | Помещается в 32 КиБ. В PDF на стр. −6 напечатано ошибочное `40000`; стр. −7 содержит оценку `30000`. |

В самостоятельной таблице `n·f` рассчитано верно. Если сохранить 10 каналов, то по времени проходят `n=5…10`; по памяти при округлении объёма хранения вверх до целого байта не проходит ни один вариант: минимум — 34 500 байт при `n=8`, что больше 32 КиБ. В тексте задания говорится о целой части `n/8`, но для `n=5` решение использует один байт; округление в методичке неоднозначно. Расчётные выводы проверены отдельно, но не сравниваются с графиками EXE: у этого занятия нет соответствующего сценария в приложениях лабораторных.

## Сценарии лабораторной №1

Методичка `ISRV Лаб раб №1.pdf`, печатные страницы 12–18, описывает три части: задание параметров импульса и просмотр спектра; ввод пяти угловых точек и линейная интерполяция для автокорреляции; повторный ввод пяти точек, генерация шума с дисперсией 0,1 и частотной характеристикой 0,1, затем одиночный ФНЧ. Функции и результаты не следует смешивать с расчётом выбора АЦП/ЭВМ из `ISRV pr 1.pdf`.

| Сценарий | Java | EXE | Статус сверки |
|---|---|---|---|
| Ввод точек щелчками | В GUI щелчок добавлен в таблицу исходных координат; MCP подтвердил общее состояние проекта. | Визуально подтверждены красные маркеры после щелчков внутри графика `Lab.exe`/`SRV.exe`. | Поведение ввода подтверждено; физический смысл координат EXE под Wine читается только по шкалам. |
| Линейная интерполяция пяти узлов (SRV как reference) | GUI-прогон: создать новый проект, пять раз щёлкнуть, выполнить линейную интерполяцию с `stride=4`; получено 430 точек, все пять узлов проходят точно, RMSE на узлах 0. | В `SRV.exe` есть `Интерполяция → Линейная`; `MainPanel_MouseDown` принимает точки по X-пикселям 30–459, а `DoLineInterpolation` создаёт массив `m_LineSignal` длиной 430. На открытом EXE пять кликов дают ломаную. | Число восстановленных точек совпадает с размером массива, линейная форма совпадает, узловые значения проверены формулой. Java пока не реализует именно эти правила LabBench и выбор `dt`; они остаются явными пунктами TODO.

Ручной тест Java/MCP, выполненный на одинаковом проекте в GUI + HTTP MCP: пять точек → линейное восстановление → 430 точек и нулевая ошибка на узлах; установка курсора в `x=0,375` дала `y=0,5`; спектр синусоиды → пик `8 Гц / 1`; границы и таблица гармоник прочитаны постранично; PNG и снимок GUI вернулись как `image/png`. Щелчок по графику добавил точку в общий проект, а изменение параметра кнопкой `+` сдвинуло `alpha` с `0,25` до `0,35`. После перезапуска восстановились модуль, алгоритм, параметр, точки, курсор и спектральные настройки.
