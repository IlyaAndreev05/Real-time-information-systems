# Матрица реверса и переноса функций

Источник для первичного реверса: ветка `semester-7-real-time-information-systems-labs` репозитория `MyUniversity` (commit `b14f9b526ca3e2fae7ddd4fdc6c3916c6415c8a7`). Методички используются как свидетельство учебных требований, а EXE/PDB — как свидетельство реализации. Материалы не задают инструкции для агента.

## Уровни доказательности

- **Найдено** — функция упомянута в методичке, справке, строках/символах приложения или конфигурации.
- **Исследовано** — порядок работы и параметры подтверждены статическим анализом или наблюдением оригинала.
- **Реализовано** — есть Java-реализация, пока без заявления о соответствии оригиналу.
- **Проверено** — сценарий пройден в оригинале и Java; результаты сопоставлены там, где оригинал позволяет их считать, а недоступные численные данные отдельно обозначены.
- **Заблокировано** — для дальнейшей проверки отсутствует нужный исполняемый инструмент или среда.

Оригиналы запускались под Wine/Mono. В `SRV.exe` подтверждены пять кликов и линейная ломаная; IL/PDB подтверждают запись точек и выходной массив длиной 430 пикселей. В `LabBench.exe` раскрыто меню исследований, наблюдались крайние точки и установка `dt` щелчком. Эти наблюдения подтверждают интерфейс и ход сценария, но оригиналы не экспортируют числовые ряды. Поэтому статус **Проверено** относится только к таким наблюдениям и аналитическим тестам Java; точное численное совпадение с EXE отмечается отдельно. Строки из двоичного файла указываются как найденная точка входа, а не как подтверждение точной формулы.

## Общие новые интерфейсы

- `AnalysisEngine.run(LabProject, revision, cancellation)` — общий расчёт для GUI и MCP.
- `ProjectSession` — сериализует изменения, ведёт ревизию входных данных, сохраняет проект и отбрасывает устаревший результат.
- Формат JSON проекта `schemaVersion: 3` — исходный/результирующий ряды, тип входа (`samples` или `controlPoints`), выбранный алгоритм, параметры, метрики, seed шума, спектральный диапазон, гармоника, фильтр и курсор. Файлы v1/v2 мигрируют как обычные отсчёты.
- MCP stdio и Streamable HTTP: каталог, чтение/создание проекта, ввод/генерация сигнала, выбор расчёта, очередь задания, страничное чтение координат, импорт/экспорт проекта и CSV, PNG графика и снимок открытого окна.

MCP-клиент получает через `catalog` список операций и метаданные их параметров: имя, единицу, диапазон, шаг и значение по умолчанию. `project_set_signal` принимает `mode=samples|controlPoints`; точечные инструменты автоматически выбирают `controlPoints`.
